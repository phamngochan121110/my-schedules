MY SCHEDULES — hướng dẫn nhanh

1. Giải nén thư mục và chạy website bằng máy chủ local (ví dụ VS Code Live Server) hoặc đưa lên một hosting HTTPS.
2. Mở link một lần khi có mạng để website được lưu vào bộ nhớ offline. Sau đó có thể cài lên màn hình chính điện thoại (Add to Home Screen / Install app).
3. Sự kiện, công việc và countdown được lưu trong bộ nhớ trình duyệt của từng thiết bị.
4. Để chuyển dữ liệu giữa máy tính và điện thoại: vào Sao lưu / khôi phục → Xuất bản sao lưu ở thiết bị thứ nhất → chuyển file JSON sang thiết bị kia → Nhập bản sao lưu.

Lưu ý:
- Lịch âm Việt Nam được tính trực tiếp trong ứng dụng theo múi giờ UTC+7.
- Nhắc nhở trình duyệt phụ thuộc quyền thông báo và khả năng chạy nền của trình duyệt; bản đầu tiên chỉ hẹn nhắc khi trang đang mở.
- Font Nunito lấy từ Google Fonts khi có mạng; phần lịch và chức năng chính vẫn chạy offline sau khi được cache, nhưng font có thể chuyển về font hệ thống.
- Để website cài đặt và chạy offline trên cả điện thoại và máy tính, cần mở qua HTTPS (hoặc localhost) ít nhất một lần. Không thể cài PWA offline chỉ bằng cách mở file HTML trực tiếp.
